# v1.0 演示录制脚本

建议录制 90 秒、1280×800、无声音或配简短旁白。录制前使用无痕窗口，避免出现个人浏览器信息。

1. `00:00-00:12`：停留登录首屏，指向“一键体验只读 Demo”。
2. `00:12-00:25`：点击进入，展示只读标识、快照模式和三任务统计。
3. `00:25-00:48`：进入路线对比，依次指向 F1、P95、Tokens 与 Calls。
4. `00:48-01:15`：进入 payment-service，滚动 Agent 消息、Tool、Evidence、Verifier 和 Arbiter。
5. `01:15-01:25`：停留 Finding 的修复与验证建议。
6. `01:25-01:30`：回到路线对比，以“复杂架构不等于更好结果”收尾。

不得在视频中打开管理员登录、服务器终端、`.env`、模型 Key 或 GitHub 私密设置。
